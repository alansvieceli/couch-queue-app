# Couch Queue

Personal Android app (React Native, Expo, TypeScript) that keeps an ordered watch queue of series and movies for each group of people you watch with, tagged by streaming service. Single user, offline-first: all data stays on the device.

## Current status

Veludo theme (dark only), header and three tabs, all implemented. Full behavior is in `docs/specs/001-couch-queue-app.md`:

- `Fila`: group selector (remembered on the device), filter chips by streaming service, numbered queue with drag-and-drop reorder through the grip on the left (only with `Todos`), tap a row to edit or delete, `+` to add (name, `Série`/`Filme`, streaming), round check to mark as watched with a 5 s `Desfazer` toast that restores the exact position.
- `Já vistos`: watched history per group (newest first) with `Visto em <data>`, `Voltar para a lista` (goes to the end of the queue) and delete with confirmation; old entries are deleted automatically after a configurable period (default 3 months).
- `Manutenção`: groups, streaming services, history period, backup, restore and reset.

## Requirements

- Node.js 24 and npm
- Android Studio with an emulator (Android only)

## Install and run

```bash
npm install
npm run android
```

`npm start` starts the Expo dev server only. `npm run build:apk` builds the release APK (needs the `android/` project generated by `npm run android`).

## Validation

```bash
npm run check
```

Runs Biome, TypeScript, Jest with coverage, and Knip. Related commands: `npm run lint`, `npm run format`, `npm run typecheck`, `npm test`, `npm run test:coverage`, `npm run dup`.

## Local data

All data lives on the device in one JSON document (AsyncStorage key `@couch-queue-app/state/v1`); the history period (`@couch-queue-app/history/v1`) and the selected group (`@couch-queue-app/selected-group/v1`) are device settings outside the backup. `Manutenção` > `Dados` exports a `couch-queue-backup-AAAA-MM-DD.cqb` file (JSON with a SHA-256 integrity hash) and restores one after validating it.

## Dependencies

Besides Expo modules, drag and drop uses `react-native-gesture-handler`, `react-native-reanimated` (with `react-native-worklets`; `babel-preset-expo` adds its Babel plugin automatically) and `react-native-reorderable-list`.

## Commits

Husky is enabled by `npm install`. Commit messages must follow `type: message` (feat, fix, docs, test, build, perf, style, refactor, chore, ci, raw, cleanup, remove). Staged files are checked with Biome through lint-staged.

## Project structure

- `src/lib/` pure, tested logic
- `src/hooks/` `useAppState` and `useDeviceSetting` (the only AsyncStorage users); `src/storage/` and `src/services/` device settings, backup files, hashing
- `src/components/` UI components: `common/` (header, tab bar, modal shell, buttons, chips) and one folder per tab
- `src/theme/` colors and typography
- `src/CouchQueueApp.tsx` app shell (fonts, splash, tabs)
- `assets/` app icon, adaptive icon and splash images
- `docs/` standards, specs, plans and app context
